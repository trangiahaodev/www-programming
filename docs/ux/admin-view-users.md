# UI Markdown: Xem danh sách người dùng
- Kế hoạch UI thuộc phạm vi đã được người dùng duyệt; không tạo plugin/UI-extension.
- Tái sử dụng layout admin-layout và CSS tokens; tiêu đề in hoa.
- Hiển thị: Mã User, tên, email, điện thoại, vai trò, trạng thái; từ khóa và phân trang.
- Form có label, lỗi cạnh trường, focus rõ; thông báo lỗi không lộ thông tin kỹ thuật.
- Xóa dùng dialog trên danh sách, tên/mã User rõ ràng, Hủy được focus trước, Escape đóng, focus trả về nút mở.
- Bảng cuộn ngang trên màn hình nhỏ; nút chạm tối thiểu 44px; Flash dùng role=status/alert.
