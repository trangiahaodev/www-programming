# Usecase: Quản trị viên thêm mới sản phẩm mỹ phẩm

| Thành phần                         | Nội dung                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tên use case**                   | Quản trị viên thêm mới sản phẩm mỹ phẩm                                                                                                                                                                                                                                                                                         |
| **Mã use case**                    | `uc002a-admin-create-product`                                                                                                                                                                                                                                                                                                    |
| **Mô tả sơ lược**                  | Quản trị viên thêm một sản phẩm mỹ phẩm mới vào kho hàng hệ thống gồm các thông tin: Mã sản phẩm, Tên sản phẩm, Thương hiệu, Danh mục, Giá bán, Giảm giá, Số lượng tồn kho, Xuất xứ, Mô tả chi tiết, Thành phần, Hướng dẫn sử dụng, Hình ảnh và Trạng thái. Hệ thống kiểm tra dữ liệu và lưu sản phẩm mới vào kho.        |
| **Actor chính**                    | Admin                                                                                                                                                                                                                                                                                                                           |
| **Actor phụ**                      | Không                                                                                                                                                                                                                                                                                                                           |
| **Tiền điều kiện (Pre-condition)** | - Quản trị viên đã đăng nhập thành công vào hệ thống với quyền quản trị viên.<br>- Hệ thống đã có ít nhất một danh mục mỹ phẩm đang hoạt động để phân loại sản phẩm.                                                                                                                                                           |
| **Hậu điều kiện (Post-condition)** | - Sản phẩm mỹ phẩm mới được lưu thành công vào kho dữ liệu của hệ thống.<br>- Hệ thống hiển thị lại màn hình danh sách sản phẩm kèm thông báo thêm mới thành công.                                                                                                                                                             |

### Luồng sự kiện chính (Main flow):

| Actor                                                                                                                                                                                                                              | Hệ thống                                                                                                                                   |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 1. Quản trị viên nhấn nút "Thêm mới sản phẩm" trên trang danh sách sản phẩm.                                                                                                                                                       |                                                                                                                                            |
|                                                                                                                                                                                                                                    | 2. Hệ thống tải danh sách danh mục đang hoạt động và hiển thị biểu mẫu thêm mới sản phẩm với các thông tin mặc định.                       |
| 3. Quản trị viên nhập thông tin sản phẩm (Mã sản phẩm, Tên sản phẩm, Thương hiệu, Danh mục, Giá bán, Giảm giá, Số lượng tồn kho, Xuất xứ, Mô tả, Thành phần, Hướng dẫn sử dụng, Hình ảnh, Trạng thái) và nhấn nút "Lưu sản phẩm". |                                                                                                                                            |
|                                                                                                                                                                                                                                    | 4. Hệ thống kiểm tra tính hợp lệ của dữ liệu đầu vào, kiểm tra danh mục hợp lệ và đảm bảo Mã sản phẩm cũng như Tên sản phẩm không bị trùng lặp. |
|                                                                                                                                                                                                                                    | 5. Hệ thống lưu trữ thông tin sản phẩm mới vào kho dữ liệu hệ thống.                                                                       |
|                                                                                                                                                                                                                                    | 6. Hệ thống chuyển sang màn hình danh sách sản phẩm và hiển thị thông báo thành công: "Thêm mới sản phẩm mỹ phẩm thành công!".              |
