# Usecase: Quản trị viên thêm mới danh mục mỹ phẩm

| Thành phần                         | Nội dung                                                                                                                                                                                                                   |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tên use case**                   | Quản trị viên thêm mới danh mục mỹ phẩm                                                                                                                                                                                    |
| **Mã use case**                    | `uc001a-admin-create-category`                                                                                                                                                                                             |
| **Mô tả sơ lược**                  | Quản trị viên thêm một danh mục mỹ phẩm mới vào hệ thống gồm các thông tin: Mã danh mục, Tên danh mục, Mô tả và Trạng thái hoạt động. Hệ thống kiểm tra tính hợp lệ và đảm bảo không trùng lặp mã cũng như tên danh mục. |
| **Actor chính**                    | Admin                                                                                                                                                                                                                      |
| **Actor phụ**                      | Không                                                                                                                                                                                                                      |
| **Tiền điều kiện (Pre-condition)** | - Quản trị viên đã đăng nhập thành công vào hệ thống với quyền quản trị viên.<br>- Quản trị viên đang ở trang quản lý danh mục mỹ phẩm.                                                                                   |
| **Hậu điều kiện (Post-condition)** | - Thông tin danh mục mới được lưu thành công vào hệ thống.<br>- Hệ thống hiển thị lại trang danh sách danh mục kèm thông báo thêm mới thành công.                                                                          |

### Luồng sự kiện chính (Main flow):

| Actor                                                                                                                           | Hệ thống                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Quản trị viên nhấn nút "Thêm mới danh mục" trên trang danh sách danh mục.                                                    |                                                                                                                                        |
|                                                                                                                                 | 2. Hệ thống hiển thị biểu mẫu thêm mới danh mục mỹ phẩm với trạng thái hoạt động mặc định được bật.                                    |
| 3. Quản trị viên nhập các thông tin danh mục (Mã danh mục, Tên danh mục, Mô tả, Trạng thái hoạt động) và nhấn nút "Lưu danh mục". |                                                                                                                                        |
|                                                                                                                                 | 4. Hệ thống kiểm tra tính hợp lệ của dữ liệu đầu vào và kiểm tra tính duy nhất của Mã danh mục và Tên danh mục trên toàn hệ thống.    |
|                                                                                                                                 | 5. Hệ thống lưu thông tin danh mục mới vào hệ thống.                                                                                   |
|                                                                                                                                 | 6. Hệ thống chuyển sang màn hình danh sách danh mục và hiển thị thông báo thành công: "Thêm mới danh mục mỹ phẩm thành công!".          |

### Luồng sự kiện thay thế (Alternate Flow):

*Đánh số bắt đầu từ bước rẽ nhánh ở luồng chính, vd: 3.1.*

| Actor                                                        | Hệ thống                                                                                               |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| 3.1. Quản trị viên nhấn nút "Hủy bỏ" hoặc quay lại danh sách. |                                                                                                        |
|                                                              | 3.2. Hệ thống hủy bỏ thao tác thêm mới, không lưu dữ liệu và hiển thị lại màn hình danh sách danh mục. |

### Luồng sự kiện ngoại lệ (Exception Flow):

*Đánh số cấp 3 dựa trên bước rẽ nhánh, vd: 2.1.1, 4.1.1, 5.1.1.*

| Actor                                                                                                                                                                                                  | Hệ thống                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 2.1.1. Phiên làm việc của Quản trị viên hết hạn hoặc tài khoản không có quyền quản trị.                                                                                                                |                                                                                                                                        |
|                                                                                                                                                                                                        | 2.1.2. Hệ thống từ chối truy cập và yêu cầu người dùng đăng nhập lại tài khoản hợp lệ.                                                 |
| 4.1.1. Dữ liệu nhập vào không hợp lệ (Mã danh mục bị để trống, chứa khoảng trắng/ký tự đặc biệt hoặc quá 20 ký tự; Tên danh mục bị để trống hoặc quá 150 ký tự; Mô tả vượt quá giới hạn 500 ký tự). |                                                                                                                                        |
|                                                                                                                                                                                                        | 4.1.2. Hệ thống giữ lại các thông tin đã nhập và hiển thị thông báo lỗi chi tiết tại từng trường dữ liệu không hợp lệ.                 |
|                                                                                                                                                                                                        | 4.1.3. Quay lại bước 3 của luồng chính để Quản trị viên chỉnh sửa dữ liệu.                                                             |
| 4.2.1. Mã danh mục nhập vào đã tồn tại trong hệ thống.                                                                                                                                                 |                                                                                                                                        |
|                                                                                                                                                                                                        | 4.2.2. Hệ thống giữ lại dữ liệu biểu mẫu và hiển thị thông báo lỗi: "Mã danh mục đã tồn tại trong hệ thống. Vui lòng chọn mã khác.".   |
|                                                                                                                                                                                                        | 4.2.3. Quay lại bước 3 của luồng chính.                                                                                                |
| 4.3.1. Tên danh mục nhập vào đã tồn tại trong hệ thống.                                                                                                                                                |                                                                                                                                        |
|                                                                                                                                                                                                        | 4.3.2. Hệ thống giữ lại dữ liệu biểu mẫu và hiển thị thông báo lỗi: "Tên danh mục đã tồn tại trong hệ thống. Vui lòng đặt tên khác.". |
|                                                                                                                                                                                                        | 4.3.3. Quay lại bước 3 của luồng chính.                                                                                                |
| 5.1.1. Hệ thống gặp sự cố trong quá trình lưu trữ dữ liệu.                                                                                                                                             |                                                                                                                                        |
|                                                                                                                                                                                                        | 5.1.2. Hệ thống hủy bỏ lưu trữ, giữ lại dữ liệu biểu mẫu và hiển thị thông báo lỗi: "Không thể lưu danh mục vào lúc này. Vui lòng thử lại sau.". |
|                                                                                                                                                                                                        | 5.1.3. Quay lại bước 3 của luồng chính.                                                                                                |
