# Usecase: Khách hàng xem và cập nhật giỏ hàng

| Thành phần                         | Nội dung                                                                                                                                                                                                                                                                                                        |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tên use case**                   | Khách hàng xem và cập nhật giỏ hàng                                                                                                                                                                                                                                                                             |
| **Mã use case**                    | `uc002b-customer-manage-cart`                                                                                                                                                                                                                                                                                   |
| **Mô tả sơ lược**                  | Khách hàng mở màn hình giỏ hàng để xem danh sách các sản phẩm đã chọn mua, đơn giá, số lượng, thành tiền từng món và tổng tiền thanh toán tạm tính. Khách hàng có thể thay đổi số lượng từng món, xóa một món hàng khỏi giỏ hoặc xóa toàn bộ giỏ hàng mua sắm tạm thời của phiên làm việc.                     |
| **Actor chính**                    | Customer (Khách hàng / Khách vãng lai)                                                                                                                                                                                                                                                                          |
| **Actor phụ**                      | Không                                                                                                                                                                                                                                                                                                           |
| **Tiền điều kiện (Pre-condition)** | Khách hàng đang truy cập vào hệ thống website PinkyCloud.                                                                                                                                                                                                                                                       |
| **Hậu điều kiện (Post-condition)** | - Danh sách sản phẩm, số lượng và tổng tiền tạm tính trong giỏ hàng tạm thời của phiên làm việc được cập nhật chính xác theo thao tác của người dùng.<br>- Chưa phát sinh đơn hàng hay thay đổi số lượng tồn kho trong cơ sở dữ liệu.                                                                         |

### Luồng sự kiện chính (Main flow):

| Actor                                                                                                                                   | Hệ thống                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Khách hàng nhấn vào biểu tượng giỏ hàng trên thanh điều hướng hoặc nhấn liên kết xem giỏ hàng.                                       |                                                                                                                                                                                                                                                                 |
|                                                                                                                                         | 2. Hệ thống kiểm tra giỏ hàng tạm thời của phiên làm việc và hiển thị màn hình giỏ hàng gồm: danh sách sản phẩm, hình ảnh, mã sản phẩm, đơn giá, ô điều chỉnh số lượng, thành tiền từng món, bảng tóm tắt đơn hàng (tổng số lượng, tiền tạm tính, phí vận chuyển) và nút thanh toán. |
| 3. Khách hàng thay đổi số lượng của một mặt hàng tại ô nhập liệu (số lượng lớn hơn hoặc bằng 1) và nhấn nút "Lưu".                      |                                                                                                                                                                                                                                                                 |
|                                                                                                                                         | 4. Hệ thống kiểm tra tính hợp lệ của số lượng cập nhật (phải là số nguyên lớn hơn hoặc bằng 1).                                                                                                                                                                 |
|                                                                                                                                         | 5. Hệ thống kiểm tra số lượng tồn kho khả dụng của sản phẩm trong kho đáp ứng đủ số lượng mới yêu cầu.                                                                                                                                                          |
|                                                                                                                                         | 6. Hệ thống cập nhật lại số lượng của mặt hàng trong giỏ hàng tạm thời, tự động tính lại thành tiền của món đó và tổng tiền của toàn bộ giỏ hàng, đồng thời hiển thị thông báo thành công: "Đã cập nhật số lượng thành công!".                                 |

### Luồng sự kiện thay thế (Alternate Flow):

*Đánh số bắt đầu từ bước rẽ nhánh ở luồng chính, vd: 2.1, 3.1, 3.3, 3.5.*

| Actor                                                                                            | Hệ thống                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2.1. Giỏ hàng của khách hàng hiện tại đang trống (chưa có sản phẩm nào).                         |                                                                                                                                                                                                                                          |
|                                                                                                  | 2.2. Hệ thống hiển thị giao diện giỏ hàng trống với thông điệp: "Giỏ hàng của bạn đang trống! Hãy khám phá bộ sưu tập mỹ phẩm chính hãng và chọn cho mình sản phẩm ưng ý nhé." kèm nút "Khám phá sản phẩm ngay" dẫn về trang danh sách sản phẩm. |
| 3.1. Khách hàng nhấn nút biểu tượng thùng rác "Xóa" tại một mặt hàng trong giỏ hàng.            |                                                                                                                                                                                                                                          |
|                                                                                                  | 3.2. Hệ thống xóa mặt hàng đó khỏi giỏ hàng tạm thời của phiên làm việc, tự động tính toán lại tổng tiền tạm tính và hiển thị thông báo thành công: "Đã xóa sản phẩm khỏi giỏ hàng!".                                                    |
| 3.3. Khách hàng nhấn nút "Xóa tất cả" trên đầu danh sách sản phẩm giỏ hàng.                     |                                                                                                                                                                                                                                          |
|                                                                                                  | 3.4. Hệ thống xóa toàn bộ các mặt hàng trong giỏ hàng tạm thời của phiên làm việc, chuyển giao diện về trạng thái giỏ hàng trống và hiển thị thông báo: "Đã làm trống giỏ hàng!".                                                      |
| 3.5. Khách hàng nhấn nút "Tiến Hành Đặt Hàng" trên bảng tóm tắt đơn hàng để thực hiện thanh toán. |                                                                                                                                                                                                                                          |
|                                                                                                  | 3.6. Hệ thống chuyển hướng khách hàng sang màn hình đặt hàng và thanh toán (chuyển tiếp sang Use Case uc003-checkout).                                                                                                                  |

### Luồng sự kiện ngoại lệ (Exception Flow):

*Đánh số cấp 3 dựa trên bước rẽ nhánh, vd: 4.1.1, 5.1.1, 5.2.1.*

| Actor                                                                                                 | Hệ thống                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 4.1.1. Số lượng cập nhật nhập vào không hợp lệ (để trống hoặc nhỏ hơn 1).                              |                                                                                                                                                        |
|                                                                                                       | 4.1.2. Hệ thống giữ nguyên số lượng cũ của sản phẩm trong giỏ và hiển thị thông báo lỗi: "Số lượng không hợp lệ!".                                     |
|                                                                                                       | 4.1.3. Quay lại bước 3 của luồng chính để Khách hàng điều chỉnh lại số lượng hợp lệ.                                                                   |
| 5.1.1. Mặt hàng yêu cầu cập nhật không còn tồn tại trong giỏ hàng.                                     |                                                                                                                                                        |
|                                                                                                       | 5.1.2. Hệ thống giữ nguyên trạng thái giỏ hàng hiện tại và hiển thị thông báo lỗi: "Sản phẩm không có trong giỏ hàng!".                                 |
|                                                                                                       | 5.1.3. Quay lại bước 2 của luồng chính để làm mới giao diện giỏ hàng.                                                                                  |
| 5.2.1. Số lượng cập nhật mới vượt quá số lượng hàng còn tồn kho khả dụng của sản phẩm.                 |                                                                                                                                                        |
|                                                                                                       | 5.2.2. Hệ thống giữ nguyên số lượng cũ của mặt hàng và hiển thị thông báo lỗi: "Số lượng cập nhật vượt quá tồn kho (chỉ còn lại [số lượng] sản phẩm)!". |
|                                                                                                       | 5.2.3. Quay lại bước 3 của luồng chính để Khách hàng chọn số lượng nhỏ hơn hoặc bằng lượng tồn kho.                                                    |
