# Usecase: Quản trị viên cập nhật sản phẩm mỹ phẩm

| Thành phần                         | Nội dung                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tên use case**                   | Quản trị viên cập nhật sản phẩm mỹ phẩm                                                                                                                                                                                                                                                                                         |
| **Mã use case**                    | `uc002b-admin-update-product`                                                                                                                                                                                                                                                                                                    |
| **Mô tả sơ lược**                  | Quản trị viên chỉnh sửa thông tin của một sản phẩm mỹ phẩm hiện có trong hệ thống (Tên sản phẩm, Thương hiệu, Danh mục, Giá bán, Giảm giá, Số lượng tồn kho, Xuất xứ, Mô tả chi tiết, Thành phần, Hướng dẫn sử dụng, Hình ảnh, Trạng thái). Mã sản phẩm là mã định danh không thể thay đổi. Hệ thống kiểm tra và cập nhật dữ liệu. |
| **Actor chính**                    | Admin                                                                                                                                                                                                                                                                                                                           |
| **Actor phụ**                      | Không                                                                                                                                                                                                                                                                                                                           |
| **Tiền điều kiện (Pre-condition)** | - Quản trị viên đã đăng nhập thành công vào hệ thống với quyền quản trị viên.<br>- Sản phẩm mỹ phẩm cần chỉnh sửa đang tồn tại trong hệ thống.                                                                                                                                                                                 |
| **Hậu điều kiện (Post-condition)** | - Thông tin sản phẩm được cập nhật thành công vào kho dữ liệu của hệ thống.<br>- Hệ thống hiển thị lại màn hình danh sách sản phẩm kèm thông báo cập nhật thành công.                                                                                                                                                           |

### Luồng sự kiện chính (Main flow):

| Actor                                                                                                                                                                                                                                  | Hệ thống                                                                                                                                       |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Quản trị viên nhấn nút "Chỉnh sửa" tại sản phẩm cần cập nhật trên trang danh sách sản phẩm.                                                                                                                                         |                                                                                                                                                |
|                                                                                                                                                                                                                                        | 2. Hệ thống tải thông tin chi tiết của sản phẩm và hiển thị biểu mẫu chỉnh sửa (Mã sản phẩm hiển thị ở chế độ chỉ đọc, không thể thay đổi).    |
| 3. Quản trị viên chỉnh sửa các thông tin cần thay đổi (Tên sản phẩm, Thương hiệu, Danh mục, Giá bán, Giảm giá, Số lượng tồn kho, Xuất xứ, Mô tả, Thành phần, Hướng dẫn sử dụng, Hình ảnh, Trạng thái) và nhấn nút "Lưu thay đổi". |                                                                                                                                                |
|                                                                                                                                                                                                                                        | 4. Hệ thống kiểm tra tính hợp lệ của dữ liệu đầu vào và kiểm tra tính duy nhất của Tên sản phẩm so với các sản phẩm khác trong hệ thống.       |
|                                                                                                                                                                                                                                        | 5. Hệ thống ghi nhận và cập nhật thông tin sản phẩm vào kho dữ liệu hệ thống.                                                                  |
|                                                                                                                                                                                                                                        | 6. Hệ thống chuyển sang màn hình danh sách sản phẩm và hiển thị thông báo thành công: "Cập nhật sản phẩm mỹ phẩm thành công!".                  |

### Luồng sự kiện thay thế (Alternate Flow):

*Đánh số bắt đầu từ bước rẽ nhánh ở luồng chính, vd: 3.1.*

| Actor                                                        | Hệ thống                                                                                                 |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| 3.1. Quản trị viên nhấn nút "Hủy bỏ" hoặc quay lại danh sách. |                                                                                                          |
|                                                              | 3.2. Hệ thống hủy bỏ các thay đổi vừa nhập, giữ nguyên dữ liệu ban đầu và hiển thị lại trang danh sách. |

### Luồng sự kiện ngoại lệ (Exception Flow):

*Đánh số cấp 3 dựa trên bước rẽ nhánh, vd: 2.1.1, 4.1.1, 5.1.1.*

| Actor                                                                                                                                                                                                     | Hệ thống                                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 2.1.1. Sản phẩm cần chỉnh sửa không tồn tại hoặc đã bị xóa khỏi hệ thống.                                                                                                                                 |                                                                                                                                        |
|                                                                                                                                                                                                           | 2.1.2. Hệ thống chuyển hướng về trang danh sách và hiển thị thông báo lỗi: "Không tìm thấy sản phẩm mỹ phẩm cần cập nhật!".            |
| 2.2.1. Phiên làm việc của Quản trị viên hết hạn hoặc tài khoản không có quyền quản trị.                                                                                                                   |                                                                                                                                        |
|                                                                                                                                                                                                           | 2.2.2. Hệ thống từ chối truy cập và yêu cầu người dùng đăng nhập lại tài khoản hợp lệ.                                                 |
| 4.1.1. Dữ liệu nhập vào không hợp lệ (Tên sản phẩm bị để trống hoặc vượt quá 255 ký tự; Danh mục chưa được chọn; Giá bán nhỏ hơn hoặc bằng 0; Số lượng tồn kho nhỏ hơn 0; Hình ảnh vượt quá độ dài).    |                                                                                                                                        |
|                                                                                                                                                                                                           | 4.1.2. Hệ thống giữ lại các thông tin đã nhập và hiển thị thông báo lỗi chi tiết tại từng trường dữ liệu không hợp lệ.                 |
|                                                                                                                                                                                                           | 4.1.3. Quay lại bước 3 của luồng chính để Quản trị viên chỉnh sửa dữ liệu.                                                             |
| 4.2.1. Tên sản phẩm mới bị trùng với tên của một sản phẩm khác đã tồn tại trong hệ thống.                                                                                                                 |                                                                                                                                        |
|                                                                                                                                                                                                           | 4.2.2. Hệ thống giữ lại dữ liệu biểu mẫu và hiển thị thông báo lỗi: "Tên sản phẩm đã tồn tại trong hệ thống. Vui lòng đặt tên khác.". |
|                                                                                                                                                                                                           | 4.2.3. Quay lại bước 3 của luồng chính.                                                                                                |
| 5.1.1. Hệ thống gặp sự cố trong quá trình lưu trữ dữ liệu.                                                                                                                                                |                                                                                                                                        |
|                                                                                                                                                                                                           | 5.1.2. Hệ thống hủy bỏ thao tác cập nhật, giữ lại dữ liệu và hiển thị thông báo lỗi: "Không thể cập nhật sản phẩm vào lúc này. Vui lòng thử lại sau!". |
|                                                                                                                                                                                                           | 5.1.3. Quay lại bước 3 của luồng chính.                                                                                                |
