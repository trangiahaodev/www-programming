# Usecase: Quản trị viên cập nhật danh mục mỹ phẩm

| Thành phần                         | Nội dung                                                                                                                                                                                                                                                                            |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tên use case**                   | Quản trị viên cập nhật danh mục mỹ phẩm                                                                                                                                                                                                                                             |
| **Mã use case**                    | `uc001b-admin-update-category`                                                                                                                                                                                                                                                      |
| **Mô tả sơ lược**                  | Quản trị viên cập nhật thông tin của một danh mục mỹ phẩm hiện có trong hệ thống gồm: Tên danh mục, Mô tả và Trạng thái hoạt động. Mã danh mục là mã định danh không thể thay đổi. Hệ thống kiểm tra tính hợp lệ và đảm bảo tên danh mục không bị trùng lặp với danh mục khác. |
| **Actor chính**                    | Admin                                                                                                                                                                                                                                                                               |
| **Actor phụ**                      | Không                                                                                                                                                                                                                                                                               |
| **Tiền điều kiện (Pre-condition)** | - Quản trị viên đã đăng nhập thành công vào hệ thống với quyền quản trị viên.<br>- Danh mục mỹ phẩm cần chỉnh sửa đang tồn tại trong hệ thống.                                                                                                                                      |
| **Hậu điều kiện (Post-condition)** | - Thông tin danh mục được cập nhật thành công vào hệ thống.<br>- Hệ thống hiển thị lại trang danh sách danh mục kèm thông báo cập nhật thành công.                                                                                                                                 |

### Luồng sự kiện chính (Main flow):

| Actor                                                                                                                                             | Hệ thống                                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Quản trị viên nhấn nút "Chỉnh sửa" tại danh mục cần cập nhật trên trang danh sách danh mục.                                                    |                                                                                                                                                |
|                                                                                                                                                   | 2. Hệ thống hiển thị biểu mẫu cập nhật kèm toàn bộ thông tin hiện tại của danh mục đã chọn (Mã danh mục ở trạng thái chỉ đọc, không cho sửa). |
| 3. Quản trị viên thay đổi các thông tin cần cập nhật (Tên danh mục, Mô tả, Trạng thái hoạt động) và nhấn nút "Cập nhật danh mục".                 |                                                                                                                                                |
|                                                                                                                                                   | 4. Hệ thống kiểm tra tính hợp lệ của dữ liệu đầu vào và kiểm tra tính duy nhất của Tên danh mục so với các danh mục khác trong hệ thống.      |
|                                                                                                                                                   | 5. Hệ thống ghi nhận các thông tin cập nhật của danh mục vào hệ thống.                                                                         |
|                                                                                                                                                   | 6. Hệ thống chuyển sang màn hình danh sách danh mục và hiển thị thông báo thành công: "Cập nhật danh mục mỹ phẩm thành công!".                 |

### Luồng sự kiện thay thế (Alternate Flow):

*Đánh số bắt đầu từ bước rẽ nhánh ở luồng chính, vd: 3.1.*

| Actor                                                        | Hệ thống                                                                                                 |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| 3.1. Quản trị viên nhấn nút "Hủy bỏ" hoặc quay lại danh sách. |                                                                                                          |
|                                                              | 3.2. Hệ thống hủy bỏ các thay đổi vừa nhập, giữ nguyên dữ liệu ban đầu và hiển thị lại trang danh sách. |

### Luồng sự kiện ngoại lệ (Exception Flow):

*Đánh số cấp 3 dựa trên bước rẽ nhánh, vd: 2.1.1, 4.1.1, 5.1.1.*

| Actor                                                                                                                                           | Hệ thống                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 2.1.1. Danh mục cần chỉnh sửa không tồn tại hoặc đã bị xóa khỏi hệ thống.                                                                       |                                                                                                                                        |
|                                                                                                                                                 | 2.1.2. Hệ thống chuyển hướng về trang danh sách và hiển thị thông báo lỗi: "Không tìm thấy danh mục mỹ phẩm cần cập nhật!".            |
| 2.2.1. Phiên làm việc của Quản trị viên hết hạn hoặc tài khoản không có quyền quản trị.                                                         |                                                                                                                                        |
|                                                                                                                                                 | 2.2.2. Hệ thống từ chối truy cập và yêu cầu người dùng đăng nhập lại tài khoản hợp lệ.                                                 |
| 4.1.1. Dữ liệu nhập vào không hợp lệ (Tên danh mục bị để trống hoặc vượt quá 150 ký tự; Mô tả vượt quá giới hạn 500 ký tự).                     |                                                                                                                                        |
|                                                                                                                                                 | 4.1.2. Hệ thống giữ lại các thông tin đã nhập và hiển thị thông báo lỗi chi tiết tại từng trường dữ liệu không hợp lệ.                 |
|                                                                                                                                                 | 4.1.3. Quay lại bước 3 của luồng chính để Quản trị viên chỉnh sửa dữ liệu.                                                             |
| 4.2.1. Tên danh mục mới bị trùng với tên của một danh mục khác đã tồn tại trong hệ thống.                                                       |                                                                                                                                        |
|                                                                                                                                                 | 4.2.2. Hệ thống giữ lại dữ liệu biểu mẫu và hiển thị thông báo lỗi: "Tên danh mục đã tồn tại trong hệ thống. Vui lòng đặt tên khác.". |
|                                                                                                                                                 | 4.2.3. Quay lại bước 3 của luồng chính.                                                                                                |
| 5.1.1. Hệ thống gặp sự cố trong quá trình lưu trữ dữ liệu.                                                                                      |                                                                                                                                        |
|                                                                                                                                                 | 5.1.2. Hệ thống hủy bỏ thao tác cập nhật, giữ lại dữ liệu và hiển thị thông báo lỗi: "Không thể cập nhật danh mục vào lúc này. Vui lòng thử lại sau.". |
|                                                                                                                                                 | 5.1.3. Quay lại bước 3 của luồng chính.                                                                                                |
