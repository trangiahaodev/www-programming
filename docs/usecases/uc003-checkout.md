# Usecase: Thanh toán đơn hàng

| Thành phần                         | Nội dung                                                                                                                                                                                                                                                                                              |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tên use case**                   | Thanh toán đơn hàng                                                                                                                                                                                                                                                                                   |
| **Mã use case**                    | `uc003-checkout`                                                                                                                                                                                                                                                                                      |
| **Mô tả sơ lược**                  | Khách hàng thực hiện đặt mua các sản phẩm trong giỏ hàng. Khách hàng cung cấp thông tin giao hàng (Họ tên người nhận, Số điện thoại, Địa chỉ nhận hàng, Phương thức thanh toán, Ghi chú) và xác nhận đặt hàng. Hệ thống kiểm tra tồn kho, tạo đơn hàng mới, cập nhật kho và làm trống giỏ hàng. |
| **Actor chính**                    | Customer (Khách hàng)                                                                                                                                                                                                                                                                                 |
| **Actor phụ**                      | Không                                                                                                                                                                                                                                                                                                 |
| **Tiền điều kiện (Pre-condition)** | - Khách hàng đã đăng nhập tài khoản người dùng vào hệ thống.<br>- Giỏ hàng có ít nhất một sản phẩm và các sản phẩm vẫn còn hàng trong kho.                                                                                                                                                           |
| **Hậu điều kiện (Post-condition)** | - Đơn hàng mới được tạo thành công trong hệ thống kèm mã đơn hàng duy nhất.<br>- Số lượng tồn kho của các sản phẩm được giảm trừ tương ứng.<br>- Giỏ hàng của khách hàng được làm trống hoàn toàn.<br>- Khách hàng nhận được thông báo xác nhận đặt hàng thành công.                               |

### Luồng sự kiện chính (Main flow):

| Actor                                                                                                                                                                    | Hệ thống                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Khách hàng nhấn nút "Tiến hành thanh toán" trên trang giỏ hàng.                                                                                                       |                                                                                                                                                       |
|                                                                                                                                                                          | 2. Hệ thống kiểm tra tài khoản đã đăng nhập và giỏ hàng có sản phẩm, sau đó hiển thị biểu mẫu thanh toán kèm tóm tắt đơn hàng (danh sách và tổng tiền). |
| 3. Khách hàng nhập các thông tin giao nhận (Họ tên người nhận, Số điện thoại, Địa chỉ giao hàng, Phương thức thanh toán, Ghi chú đơn hàng) và nhấn "Xác nhận đặt hàng". |                                                                                                                                                       |
|                                                                                                                                                                          | 4. Hệ thống kiểm tra tính hợp lệ của thông tin giao nhận và kiểm tra lại số lượng tồn kho của từng sản phẩm trong giỏ hàng.                          |
|                                                                                                                                                                          | 5. Hệ thống tạo đơn hàng mới, ghi nhận các món hàng, giảm trừ số lượng tồn kho của các sản phẩm tương ứng và làm trống giỏ hàng.                      |
|                                                                                                                                                                          | 6. Hệ thống hiển thị màn hình xác nhận đặt hàng thành công kèm mã đơn hàng, thông tin người nhận, danh sách món hàng và tổng tiền cần thanh toán.     |

### Luồng sự kiện thay thế (Alternate Flow):

*Đánh số bắt đầu từ bước rẽ nhánh ở luồng chính, vd: 3.1.*

| Actor                                                                         | Hệ thống                                                |
| ----------------------------------------------------------------------------- | ------------------------------------------------------- |
| 3.1. Khách hàng nhấn liên kết "Quay lại giỏ hàng" để chỉnh sửa các món hàng. |                                                         |
|                                                                               | 3.2. Hệ thống chuyển về màn hình quản lý giỏ hàng.      |

### Luồng sự kiện ngoại lệ (Exception Flow):

*Đánh số cấp 3 dựa trên bước rẽ nhánh, vd: 2.1.1, 2.2.1, 4.1.1, 4.2.1, 5.1.1.*

| Actor                                                                                                                                                  | Hệ thống                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2.1.1. Khách hàng chưa đăng nhập tài khoản vào hệ thống hoặc phiên đăng nhập hết hạn.                                                                 |                                                                                                                                                  |
|                                                                                                                                                        | 2.1.2. Hệ thống yêu cầu khách hàng đăng nhập tài khoản để tiếp tục thanh toán.                                                                   |
| 2.2.1. Giỏ hàng hiện tại đang trống.                                                                                                                   |                                                                                                                                                  |
|                                                                                                                                                        | 2.2.2. Hệ thống hiển thị cảnh báo: "Giỏ hàng của bạn đang trống! Vui lòng chọn sản phẩm trước khi thanh toán." và chuyển về trang danh sách sản phẩm. |
| 4.1.1. Thông tin giao nhận không hợp lệ (Họ tên người nhận bị để trống; Số điện thoại không đúng định dạng; Địa chỉ giao hàng bị để trống).          |                                                                                                                                                  |
|                                                                                                                                                        | 4.1.2. Hệ thống giữ lại thông tin đã nhập và hiển thị thông báo lỗi chi tiết tại từng trường dữ liệu vi phạm.                                   |
|                                                                                                                                                        | 4.1.3. Quay lại bước 3 của luồng chính để Khách hàng điều chỉnh thông tin.                                                                      |
| 4.2.1. Một hoặc nhiều sản phẩm trong giỏ hàng không đủ số lượng tồn kho tại thời điểm đặt hàng.                                                        |                                                                                                                                                  |
|                                                                                                                                                        | 4.2.2. Hệ thống hủy bỏ quá trình tạo đơn hàng, hiển thị thông báo lỗi sản phẩm hết hàng hoặc không đủ số lượng trong kho và chuyển về giỏ hàng.  |
| 5.1.1. Hệ thống gặp sự cố trong quá trình lưu trữ thông tin đơn hàng.                                                                                  |                                                                                                                                                  |
|                                                                                                                                                        | 5.1.2. Hệ thống hủy bỏ tạo đơn hàng, giữ nguyên giỏ hàng và hiển thị thông báo lỗi: "Không thể hoàn tất đặt hàng lúc này. Vui lòng thử lại sau!". |
